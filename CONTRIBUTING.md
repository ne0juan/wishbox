# Contributing to Wishbox

Wishbox is currently a product discovery project. The repository begins with a product thesis and a seven-day validation plan; there is no production app yet.

## Good first contributions

- Point out a flaw in the experiment design or a confounding factor.
- Suggest a more precise, kinder Chinese reading or user-facing prompt.
- Improve accessibility, privacy, reporting, or moderation workflows.
- Propose a small mobile prototype that tests the two reveal choices fairly.

Open an issue to discuss a substantial change before implementing it. For a focused change, make a branch and open a pull request that describes the user problem, the change, and how it was checked.

## Boundaries

- Never commit real participant wishes, replies, contact details, credentials, or study exports. Use invented examples in public documentation and code.
- Do not present generated text as a real person's message.
- Keep the prototype's two choices equally prominent so the validation remains interpretable.
- Treat emotional-support features as sensitive: design for consent, deletion, moderation, and a clear escape path.
